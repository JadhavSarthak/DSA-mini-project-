# Natural Language Processing and Computational Linguistics

Natural language processing (NLP) bridges computer science and human linguistics to enable software to parse, analyze, comprehend, and generate natural languages.

Foundational text preprocessing stages include sentence boundary detection, tokenization, stemming (such as the Porter stemmer), lemmatization, and part-of-speech (POS) tagging. N-gram models estimate the probability of upcoming words based on previous word histories.

Modern NLP utilizes dense vector embeddings where semantically similar words reside close to each other in high-dimensional vector spaces. Classical models like Word2Vec and GloVe learned static word embeddings, whereas modern transformer language models produce contextualized embeddings where a word's vector representation shifts depending on surrounding context.

Key application domains include machine translation, sentiment analysis, named entity recognition (NER), query autocomplete suggestions, and automated text summarization.
