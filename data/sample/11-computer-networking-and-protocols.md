# Computer Networking and Transport Protocols

Computer networking connects distributed devices across local area networks (LANs) and wide area internetworks using standardized layered protocol suites such as the OSI seven-layer model and the pragmatic TCP/IP stack.

At the transport layer, the Transmission Control Protocol (TCP) provides reliable, connection-oriented byte-stream delivery through three-way handshakes, sequence tracking, cumulative acknowledgments, sliding-window flow control, and adaptive congestion control algorithms like Cubic and BBR. In contrast, the User Datagram Protocol (UDP) offers lightweight, connectionless datagram transport with minimal protocol overhead, favored by real-time streaming, online gaming, and DNS lookups.

The Internet Protocol (IPv4 and IPv6) handles logical packet addressing and routing across autonomous network domains using routing protocols like BGP (Border Gateway Protocol) and OSPF. Modern web protocols like HTTP/2 and HTTP/3 multiplex requests over persistent sessions, with HTTP/3 replacing TCP with the QUIC transport protocol built on top of UDP to eliminate head-of-line blocking.
