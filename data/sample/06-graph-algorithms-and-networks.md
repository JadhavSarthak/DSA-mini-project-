# Graph Algorithms and Network Analysis

Graphs model pairwise relational systems using vertices (nodes) and connecting edges, which may be directed or undirected, weighted or unweighted.

Graph representations typically rely on adjacency matrices for dense graphs or adjacency lists for sparse graphs. Fundamental graph traversal algorithms include Breadth-First Search (BFS), which explores neighbor nodes layer by layer to discover shortest unweighted paths, and Depth-First Search (DFS), which traverses deep into branches using recursion or an explicit stack.

Shortest path algorithms in weighted graphs include Dijkstra's algorithm for non-negative edge weights and the Bellman-Ford algorithm for graphs with potential negative edges. Minimum spanning tree algorithms such as Kruskal's and Prim's find cycle-free subgraphs connecting all vertices with minimal total edge weight.

In information retrieval and citation analysis, link analysis algorithms such as Google's PageRank and HITS model user navigation as random walks across directed document graphs to score authority and importance.
