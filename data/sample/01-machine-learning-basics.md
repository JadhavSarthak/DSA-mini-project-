# Machine Learning Basics and Core Paradigms

Machine learning is a subfield of artificial intelligence that focuses on building algorithmic systems capable of learning patterns directly from data rather than relying exclusively on explicit hand-crafted rules. 

In supervised learning, algorithms learn a mapping from input features to target outputs using labeled training datasets. Common supervised tasks include classification and numerical regression. Gradient descent optimization iteratively updates model parameters to minimize a mathematical loss function, such as mean squared error or cross-entropy loss.

Unsupervised learning identifies hidden structures and representations in unlabeled data. Clustering techniques like k-means and hierarchical clustering group similar instances, while dimensionality reduction methods such as principal component analysis (PCA) project high-dimensional data into lower dimensions.

Model generalization is evaluated using separate training, validation, and testing sets. Overfitting occurs when a machine learning model memorizes training noise rather than generalizable signals, which practitioners mitigate through regularization techniques, dropout, and cross-validation.
